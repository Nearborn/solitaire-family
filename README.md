# Solitaire Collection — Android Family Edition

Free, ad-free 18-game Solitaire collection built with Python/Pygame and packaged as an installable Android-friendly web app.

The complete source, card images, sound effects, test suite, and GitHub Pages deployment workflow will be committed here. The browser build is generated automatically using Pygbag.
